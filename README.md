# The Cutting Edge Carpenters Website

Responsive static website for **The Cutting Edge Carpenters**, serving Stellenbosch, the Cape Winelands and Parys in the Free State, South Africa.

## Pages

- `index.html` — homepage
- `kitchens.html` — kitchen and cupboard projects
- `decks-pergolas.html` — decks and pergola projects
- `cupboards-shelving.html` — cupboards and shelving projects
- `custom-projects.html` — custom carpentry projects

## Features

- Responsive sidebar/mobile navigation
- Mobile top navigation that hides on downward scroll and returns on upward scroll
- Search-only project galleries with working pagination
- GLightbox project galleries with touch and keyboard navigation
- Swiper testimonials
- WhatsApp, telephone and email quotation CTAs
- Local SEO metadata and structured data
- `robots.txt` and `sitemap.xml`
- Lazy-loaded project imagery
- Keyboard focus states, skip navigation and reduced-motion support

## Technology

- HTML5
- CSS3
- Vanilla JavaScript
- Bootstrap Icons (icons only)
- Swiper (homepage testimonials)
- GLightbox (project galleries)
- AOS (limited homepage reveal animations)

## Deployment

The site is static and can be deployed directly with GitHub Pages. GitHub Pages should use **GitHub Actions** as its publishing source when the Pages workflow is enabled.
